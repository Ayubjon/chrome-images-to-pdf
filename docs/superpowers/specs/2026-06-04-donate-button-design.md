# Дизайн: кнопка «Поддержать» (Binance Pay)

**Дата:** 2026-06-04
**Статус:** утверждён, готов к плану реализации
**Базовая версия:** v1.1.0 → поднимается до **1.2.0**

## Цель

Добавить в попап ненавязчивую ссылку доната, открывающую страницу Binance Pay
разработчика. Выбран Binance Pay, т.к. разработчик из Таджикистана, а
Buy Me a Coffee / Ko-fi / PayPal там получать выплаты не позволяют (Stripe не
поддерживает страну).

## UI и размещение

Тонкая полоска внизу попапа, под футером, отделённая верхней границей.
По центру — небольшая неяркая ссылка с подписью из i18n:
- en: «☕ Support the developer»
- ru: «☕ Поддержать разработчика»

Стиль: приглушённый цвет, мелкий шрифт; не конкурирует с основным сценарием.

## Поведение

Обычная ссылка `<a target="_blank" rel="noopener">`, открывает `DONATE_URL`
(Binance Pay «Pay Me» ссылку) в новой вкладке. **Новых разрешений не нужно** —
это просто открытие URL. На сбор PDF не влияет.

## Конфигурация

- В `src/popup.js` — константа `DONATE_URL` (одна строка для замены).
- Значение по умолчанию — заметная заглушка `'BINANCE_PAY_URL_HERE'`.
- **Логика скрытия:** если `DONATE_URL` равен заглушке (или пустой), полоска
  доната скрыта (`hidden`), чтобы не публиковать «мёртвую» кнопку. Как только
  вписан реальный URL — полоска показывается, а `href` ссылки выставляется в
  `DONATE_URL`.
- Проверка «является ли значение заглушкой» выносится в чистую функцию
  `isConfiguredDonateUrl(url)` в `src/lib/donate.js` — покрывается юнит-тестом.

## i18n

Добавить ключ `support` в `_locales/en/messages.json` и
`_locales/ru/messages.json`:
- en: `"Support the developer ☕"`
- ru: `"Поддержать разработчика ☕"`

Подпись подставляется существующим механизмом `data-i18n` (ссылка получает
`data-i18n="support"`).

## Как разработчику получить ссылку Binance Pay

В приложении Binance: раздел **Pay → Receive / «Pay Me» → создать ссылку/QR →
скопировать**. Вставить в `DONATE_URL`. (Путь в приложении может отличаться —
сверить на месте.)

## Обработка ошибок / краевые случаи

- `DONATE_URL` = заглушка/пусто → полоска скрыта (см. выше).
- Клик по ссылке всегда открывает новую вкладку с `DONATE_URL` (валидность
  адреса — ответственность разработчика, заполняющего константу).

## Тестирование

- **Юнит (TDD, Node):** `isConfiguredDonateUrl` — `false` для заглушки и пустой
  строки, `true` для реального URL. Существующие 16 тестов остаются зелёными.
- **Ручной ре-тест:** при заглушке полоски нет; после подстановки реального
  URL полоска появляется, клик открывает нужный адрес в новой вкладке; подпись
  меняется по локали браузера.

## Вне рамок

- Регистрация в Binance и генерация Pay-ссылки — на разработчике (в константу
  вписывается готовый URL).
- QR-код в попапе, суммы, выбор валюты — не делаем (YAGNI).
- Версия → 1.2.0.
