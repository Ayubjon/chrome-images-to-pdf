# Дизайн: кнопка «Поддержать» (крипто-адрес + копирование)

**Дата:** 2026-06-04
**Статус:** утверждён (ревизия), реализовано
**Базовая версия:** v1.1.0 → **1.2.0**

## История решения

Изначально планировался Binance Pay по ссылке. При настройке выяснилось, что
Binance Pay даёт только **платёжные ссылки с фиксированной суммой и сроком**
(до 1 года, потом истекают), а постоянные методы (Binance ID, Receive QR) не
являются кликабельной ссылкой. Для кнопки в опубликованном расширении истечение
срока недопустимо. Поэтому форма доната изменена на **копирование постоянного
крипто-адреса USDT**. Выбранная сеть — **Ethereum (ERC-20)**; адрес в формате
`0x…` (EVM).

## Цель

Добавить в попап ненавязчивую полоску «Поддержать разработчика» с крипто-адресом
и кнопкой «Копировать». Полоска скрыта, пока адрес не задан.

## UI и размещение

Тонкая полоска внизу попапа (под футером), отделённая верхней границей, по центру:
- подпись «☕ Поддержать разработчика» / «Support the developer ☕»;
- сам адрес моноширинным шрифтом + кнопка **«Копировать»**;
- метка сети **USDT · ERC-20** (технический текст, не локализуется).

## Поведение

Клик по «Копировать» → `navigator.clipboard.writeText(DONATE_ADDRESS)` (в попапе
работает по жесту пользователя, **новых разрешений не нужно**). На ~1.5 секунды
кнопка показывает «Скопировано!», затем возвращает прежний текст. Если Clipboard
API недоступен — адрес выделяется для ручного копирования (запасной вариант).

## Конфигурация

- В `src/popup.js` — константа `DONATE_ADDRESS` (одна строка для замены).
- Заглушка для «не настроено» — `'YOUR_USDT_ADDRESS_HERE'` (нейтральна по сети).
- Если адрес = заглушка/пусто — полоска скрыта (`hidden`), чтобы не публиковать
  «мёртвую» кнопку. При реальном адресе полоска показывается.
- Проверка вынесена в чистую функцию `isConfiguredDonateValue(value)` в
  `src/lib/donate.js` — покрыта юнит-тестом.

## i18n

Ключи в `_locales/en` и `_locales/ru`:
- `support`: «Support the developer ☕» / «Поддержать разработчика ☕»
- `copy`: «Copy» / «Копировать»
- `copied`: «Copied!» / «Скопировано!»

Подписи `support` и `copy` — через `data-i18n`; `copied` — из JS при клике.

## Обработка ошибок / краевые случаи

- `DONATE_ADDRESS` = заглушка/пусто → полоска скрыта.
- Clipboard API бросает исключение → запасной вариант: выделить текст адреса.

## Тестирование

- **Юнит (TDD, Node):** `isConfiguredDonateValue` — `false` для заглушки, пустой
  строки и не-строки; `true` для реального адреса. Остальные тесты зелёные.
- **Ручной ре-тест:** при заглушке полоски нет; при реальном адресе полоска
  появляется, «Копировать» кладёт адрес в буфер и показывает «Скопировано!»;
  подписи меняются по локали.

## Вне рамок

- QR-код адреса в попапе — не делаем в этой итерации (YAGNI).
- Версия → 1.2.0.

## Заметки для разработчика (важно)

- **Метка сети и адрес обязаны совпадать.** Адрес `0x…` — это EVM-формат
  (Ethereum/BSC/Polygon), НЕ Tron. В расширении заявлена сеть **ERC-20
  (Ethereum)** — донатеры должны слать USDT именно по Ethereum.
- **Комиссии Ethereum высокие**, поэтому мелкие донаты на ERC-20 отправителю
  невыгодны. Более дешёвые альтернативы для будущего — BEP-20 (BSC) или TRC-20
  (Tron); при смене сети обязательно сменить и метку, и адрес.
- Перед тем как полагаться на адрес, проверь его тестовой отправкой малой суммы.
